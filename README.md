# Sistema Norteador - Lavação de Carros 🚗

Projeto desenvolvido como parte da atividade **Mão na Massa 1** da disciplina de **Desenvolvimento Web I**.

## 📌 Sobre o Projeto
O **Sistema Norteador** é uma simulação de aplicação web para gerenciamento de serviços de lavação de veículos. Nesta primeira etapa, foi implementada a interface gráfica mínima utilizando **HTML5 puro**, focando em acessibilidade, estrutura semântica e boas práticas de formulários.

## 📂 Estrutura do Projeto
* `index.html`: Página inicial com o menu e links de navegação.
* `cliente.html`: Formulário de cadastro de cliente (nome, endereço, e-mail, celular, usuário e senha).
* `veiculo.html`: Formulário de cadastro de veículo (marca, modelo e placa).

## 🛠️ Tecnologias Utilizadas
* HTML5 (Tags semânticas, atributos de validação e controle de formulários).
